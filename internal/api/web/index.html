服务版本：--
本机 IPv4 是运营商 CGNAT，A 记录解析出来的地址外部连不进来； AAAA 只有 iface:wlan0 的地址真正可用（且需路由器放行入站）。 4G 的 IPv6 只下发地址、数据面不通，用它做 AAAA 没有意义。
同一域名可以建两条（一条 A、一条 AAAA），也可以只建一条。每 5 分钟检查一次，地址没变不会调用 API。
